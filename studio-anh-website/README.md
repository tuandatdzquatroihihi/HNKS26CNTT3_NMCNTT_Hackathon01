# DỰ ÁN WEBSITE STUDIO CHỤP ẢNH

## Website được tạo ra để **quản lý** các lịch chụp ảnh một cách **dễ dàng**, **tiện lợi** đồng thời lọc ra **_lỗi_** phát sinh của trang web

## Bảng thư mục và nội dung

| Thư mục | Nội dung |
| :---: | :---: |
| backup | Chứa các file backup của dự án |
| data | Chứa dữ liệu khách hàng |
| docs | Chứa thông tin bảng giá |
| logs | Chứa các bản ghi lỗi |
| media | Chứa logo dự án |
## Lệnh liệt kê nội dung dự án

Ở thư mục gốc **(.\studio-anh-website)**, nhập lệnh sau để liệt kê toàn bộ nội dung dự án
```powershell
ls -r -Force
```
